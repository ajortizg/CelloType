CelloType example data: https://doi.org/10.5281/zenodo.22736357

From the repository root, run:
  python download.py --list
  python download.py example_tissuenet.zip
  python download.py example_codex_crc.zip
  python download.py example_xenium.zip

Files are saved under data/. Extract the required ZIP and follow its tutorial.
